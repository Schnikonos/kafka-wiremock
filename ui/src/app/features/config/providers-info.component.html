Hybrid Provider Selection

Kafka Wiremock automatically detects which JMS providers are installed and available for use. You can:

  • Use Available Providers: Configure queue managers with any installed provider
  • Install Additional Providers: Copy the pip install command and run it to enable more providers
  • Use Multiple Providers Together: Mix different providers in the same configuration
  • Mix Message Types: Single rule can input from Kafka and output to JMS (or vice versa)

Configuration Example

queue_managers:
  qm_ibm:
    provider: ibm_mq
    broker_url: localhost(1414)
    channel: DEV.APP.SVRCONN
    queue_manager: QM1
    username: app_user

  qm_activemq:
    provider: activemq
    broker_url: activemq:61613
    username: admin

  qm_rabbitmq:
    provider: rabbitmq
    broker_url: rabbitmq:5672
    username: guest
    virtual_host: /
